Nextcloud İçin Sunulan Collabora Eklentisinde Kritik Açık İstismar Ediliyor

Nextcloud platformunda isteğe bağlı olarak kullanılan Collabora Online dahili CODE sunucusu uygulamasında (richdocumentscode) kritik bir komut çalıştırma açığının istismar edildiği bildirildi. CVE-2026-110447 olarak tanımlanan güvenlik açığı, uygulamanın proxy.php uç noktasına kötü amaçlı istek gönderilerek işletim sistemi komutlarının tetiklenmesine yol açıyor. Saldırının başarılı olması için dahili sunucunun yeniden başlatma, çökme veya güncelleme gibi nedenlerle durdurulmuş olması gerekirken, herhangi bir kimlik doğrulaması ya da kullanıcı etkileşimi aranmıyor.

Sistem yöneticilerinin aktardığı raporlara göre saldırılar resmi güvenlik bülteni ve CVE kaydından yaklaşık bir ay önce, eylül ayı ortalarında başladı. Güvenlik açığını kullanan saldırganların sistemlere PHP tabanlı web kabukları yerleştirdiği; şifre veritabanları, parola yöneticisi kayıtları ve kripto para cüzdanlarını aradığı tespit edildi. Collabora, açığın yalnızca isteğe bağlı dahili CODE sunucusu uygulamasını kapsadığını; bağımsız sunucuların, Docker, RPM/DEB ve Nextcloud All-in-One kurulumlarının etkilenmediğini duyurdu.

Zafiyete ilişkin düzeltme 9 Eylül'de hazırlanıp 11 Eylül'de yayımlanan 26.4.303 sürümüyle sunulmasına rağmen, resmi CVE kaydı ve güvenlik duyurusu 14 Ekim'de açıklandı. Collabora, bildirimdeki gecikmeyi yapay zeka kaynaklı güvenlik raporlarının GitHub üzerindeki CVE işleme süreçlerinde yarattığı yoğunluğa bağladı. Uzmanlar, yöneticilere uygulamanın en az 26.4.303 sürümüne güncellenmesini ya da ihtiyaç duyulmuyorsa tamamen kaldırılmasını tavsiye ediyor.

NEDEN ÖNEMLİ?

CVE-2026-110447 kodlu açık, kimlik doğrulaması gerektirmeden sunucularda uzaktan komut çalıştırılmasına ve parola ile kripto para cüzdanlarının hedef alınmasına zemin hazırlıyor.
