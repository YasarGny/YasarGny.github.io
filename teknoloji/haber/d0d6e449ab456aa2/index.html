Ekim Windows Server Güncellemeleri Exchange E-Posta Akışında Sorunlara Yol Açtı

20.10.2026BleepingComputer

Microsoft, Windows Server 2019 ve sonraki sürümler için dağıtılan Ekim 2026 güvenlik güncellemelerinin ardından bazı yerel Exchange Server altyapılarında e-posta erişimi ve gönderim sorunları yaşandığını açıkladı. Güncellemeyi yükleyen müşterilerin Outlook Web App (OWA) oturumu açamadığı, giden postaların Giden Kutusu'nda takılı kaldığı ve posta kutusu kopyalama süreçlerinde aksamalar oluştuğu aktarıldı.

Yapılan incelemelere göre sorun, Ekim 2026 güncellemesiyle Endpoint Mapper bileşenine getirilen bellek kullanım sınırından kaynaklanıyor. Sistemde varsayılan olarak tanımlanan 512 eşzamanlı arama çağrısı limiti, Exchange Server gibi yoğun iş yükü barındıran ortamlarda yetersiz kalarak 'MapiExceptionMdbOffline' ve 'Event ID 1006' hatalarına yol açıyor.

Microsoft, aksaklığın Exchange için çıkarılan güncellemeden kaynaklanmadığını ve Exchange güvenlik yamalarının kesinlikle kaldırılmaması gerektiğini vurguladı. Sorunun çözümü için kalıcı bir yama üzerinde çalışılırken, yöneticilere kayıt defteri üzerinden çağrı sınırını artıran bir komut çalıştırmaları ve ardından sunucuyu yeniden başlatmaları önerildi.

Neden önemli?

Kurumsal e-posta altyapılarını yöneten Windows Server ve Exchange sistemlerinde iş akışını durduran bağlantı ve teslimat sorunlarının kaynağını ve çözüm adımlarını açıklaması açısından önemlidir.
