Windows Server 2022 Temel Desteğin Sonuna Geldi

Microsoft, Windows Server 2022'nin temel destek süresinin tamamlandığını ve sistemin genişletilmiş destek aşamasına geçtiğini açıkladı. Şirket, Ekim 2026 güvenlik güncelleştirmesinin bu sürüm için sunulan son temel destek güncellemesi olduğunu duyurdu.

Eylül 2021'de 10 yıllık Uzun Vadeli Hizmet Kanalı (LTSC) sürümü olarak genel kullanıma sunulan Windows Server 2022, 14 Ekim 2031 tarihine kadar ek bir ücret talep edilmeksizin aylık güvenlik güncellemelerini almaya devam edecek. Ayrıca Datacenter: Azure Edition sürümünü kullanan sistemler için anında yama (hotpatching) imkânı Ekim 2027'ye kadar uzatıldı.

Microsoft, sistem yöneticilerine tam temel destekten faydalanabilmeleri için Kasım 2024'te yayımlanan Windows Server 2025'e geçiş planlamalarını önerdi. Şirket aynı zamanda Windows 11 24H2 Home ve Pro sürümlerinin artık güvenlik ve önizleme güncellemelerini almayacağını belirterek kullanıcıları Windows 11 26H2 sürümüne yükseltmeye çağırdı.

NEDEN ÖNEMLİ?

Kurumsal sunucu altyapılarını yöneten BT ekiplerinin güvenlik, güncelleme ve Windows Server 2025'e geçiş planlamalarını doğrudan etkilemektedir.
