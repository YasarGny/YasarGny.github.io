SİBER GÜVENLİK

F5, Kritik NGINX Güvenlik Açıkları İçin Acil Yamalar Yayınladı

20.10.2026BleepingComputer

F5, NGINX web sunucusu yazılımlarında saldırganların uzaktan kod çalıştırmasına izin verebilecek üçü kritik seviyede olmak üzere çeşitli güvenlik açıkları için plan dışı güvenlik yamaları çıkardı. Etkilenen ürünler arasında NGINX Plus, NGINX Open Source, NGINX Ingress Controller, NGINX Gateway Fabric ve NGINX Instance Manager yer alıyor.

Kritik güvenlik kusurlarının ikisi 'ngx_http_v3_module' modülünde (CVE-2026-15176 ve CVE-2026-97205), diğeri ise NGINX 'map' yönergesinde (CVE-2026-93479) saptandı. Ayrıcalıksız uzaktan saldırganlar, varsayılan olmayan yapılandırmalarda bu açıkları kullanarak hizmet reddi (DoS) oluşturabiliyor ya da bellek yönetimi hataları yoluyla NGINX çalışan süreçlerinin çökmesine yol açabiliyor. Adres Alanı Düzeni Rastgeleleştirmesi (ASLR) koruması kapalı veya atlatılabilir durumdaki sistemlerde kod çalıştırılabileceği belirtiliyor.

F5, bu güvenlik açıklarının henüz fiili saldırılarda kullanıldığına dair bir tespit olmadığını bildirdi. Yamaları hemen kuramayan yöneticilere, 'alias' yönergesinden kaçınma, eşzamansız dosya G/Ç (AIO) özelliğini devre dışı bırakma ve adlandırılmış yakalamalar kullanma gibi geçici yapılandırma yöntemleri tavsiye edildi.

Neden önemli?

Dünya çapında çok sayıda sunucuda çalışan NGINX yazılımlarında yetkisiz kişilerin kod çalıştırmasına imkan veren kritik açıkların kapatılması küresel sunucu güvenliği açısından önem taşımaktadır.
