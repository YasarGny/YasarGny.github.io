OpenAI Karar Modelleri Pazarına Decisions API ile Giriş Yaptı

23.10.2026TechCrunch

OpenAI, 29 Eylül tarihindeki geliştirici gününde duyurduğu Decisions API modelini tüm müşterilerinin erişimine açtı. TypeSafe şirketinin Jev modeliyle öncülük ettiği süper sınıflandırıcı karar modelleri pazarına dahil olan sistem, verilen seçenekler arasında hızlı seçim yaparak bir güven puanı üretiyor.

OpenAI API Ürün Lideri Nikunj Handa, ürün için sıfırdan özel bir model eğitmek yerine ChatGPT Luna'yı yeniden yapılandırarak çıkarım hızını artırdıklarını ve maliyeti düşürdüklerini söyledi. Handa, bu optimizasyonla işlem sürelerinin 1 ila 3 saniye aralığından 100-180 milisaniye seviyelerine indirildiğini belirtti. Genel sürüme ses ve görsel modaliteler eklenirken, gecikmeyi düşürmek için kaynaklar coğrafi olarak hedeflendi.

Modeli ilk deneyen şirketlerden Speak'in Teknoloji Direktörü Andrew Hsu, eylemler arası bekleme süresinin 1,4 saniyeden 0,13 saniyeye indiğini aktardı. Bağımsız kıyaslama testlerinden AIM System One Index ve Artificial Analysis Decision Index listelerinde Liquid'in D1 Ultra modeli önde yer alırken, OpenAI'ın modeli sırasıyla sekizinci ve on dördüncü sırada kendine yer buldu. Handa, gelecekte 60 milisaniye seviyelerine ulaşarak videolardaki her kare için API çağrısı yapılabileceğini öngördüklerini paylaştı.

Neden önemli?

Hızlı ve ucuz sınıflandırma sağlayan karar modelleri pazarında TypeSafe gibi girişimlerle rekabeti artırırken iş akışlarında LLM maliyetlerini düşürme potansiyeli taşıyor.
